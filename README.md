# Две в Цвете

Самостоятельный проект сайта. Другие сайты и их репозитории не используются для публикации.

## Запуск
Node.js: `npm start`, затем http://127.0.0.1:4175.
Для статического хостинга: index.html, styles.css, app.js, data.js, config.js, favicon.svg, assets/, fonts/.

## Что готово
Адаптивная витрина, поиск, категории, фильтр цен, сортировка, избранное, корзина с выбором части товаров, форма доставки и предварительными тарифами, квиз, подписки, сертификаты, сезонный раздел, FAQ, контакты, шесть отзывов с правильными фото. Заявка передаётся через WhatsApp только после отправки пользователем. Рейтинг 4,9 указан по заданию заказчика.

## До запуска продаж
1. Получить прямую ссылку на карточку Google Maps и подставить mapsUrl в config.js. Сейчас ссылка открывает поиск Google Maps по точному названию и адресу.
2. Заполнить реальные ссылки VK, Telegram, MAX в config.js. Неизвестные ссылки не показываются.
3. Передать каталог с ценами, составами, остатками и одинаковыми фонами фото.
4. Подключить backend, Posiflora, геокодирование/зоны доставки, платежи и консультант согласно INTEGRATIONS.md.
5. Уточнить данные оператора/полное имя ИП, реквизиты и согласовать юридические тексты. Текущие тексты описывают фактический режим прототипа.
6. Фото сертификатов, подписок S/M/L, мастер-классов и кейсов пока ожидаются; места под них предусмотрены.

Онлайн-оплата отключена. Балансы бонусов не имитируются. Район пока выбирается вручную, автоматическое определение и выбор адреса на карте требуют подключения Google Maps и подтверждённых зон.
